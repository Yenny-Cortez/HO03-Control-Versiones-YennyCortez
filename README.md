# Proyecto: Sistema de Gestión de Versiones

## Descripción del caso práctico
Una empresa de desarrollo de software necesita organizar los archivos de sus proyectos y mantener un historial de cambios para evitar modificar archivos sin control y poder recuperar versiones anteriores fácilmente.

## Objetivo del repositorio
Implementar un repositorio en GitHub para organizar los archivos de un proyecto, registrar los cambios de manera estructurada y demostrar el uso de ramas (`branches`), commits y pull requests para trabajar de forma colaborativa y ordenada.
